    Git e GitHub

    Qual é a diferença?

    Git

    Programa instalado no teu computador que guarda o histórico das alterações ao código.

    GitHub

    Site online onde se guardam repositórios Git, para partilhar e trabalhar em equipa.

    Conceitos principais

    • Repositório: a pasta do projeto com todo o histórico.
    • Commit: uma "fotografia" das alterações, com uma mensagem.
    • Branch: uma linha de trabalho paralela, para testar sem estragar o projeto principal.
    • Issue: uma tarefa, erro ou ideia registada no GitHub.
    • Pull Request: um pedido para juntar o teu branch ao principal, depois de a equipa rever.

    Comandos básicos

    git init                  # cria um repositório
git add .                 # prepara todas as alterações
git commit -m "Mensagem"  # guarda as alterações
git push                  # envia para o GitHub
git pull                  # traz as alterações do GitHub
git branch nova-ideia     # cria um branch

    Faz commits pequenos e com mensagens claras, como "Adiciona página de FAQ".
