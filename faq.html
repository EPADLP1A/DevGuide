    Perguntas frequentes

    O que é programação?

    É escrever instruções para o computador executar. Um programa é uma lista de passos que resolve um problema.

    Preciso de saber matemática para programar?

    Para começar, só precisas da matemática básica. Só áreas específicas, como jogos 3D ou ciência de dados, pedem mais.

    O que é HTML?

    É a linguagem que define a estrutura de uma página web. Vê a página de HTML.

    Qual é a diferença entre Git e GitHub?

    Git é a ferramenta que guarda o histórico do código. GitHub é o site onde se partilham repositórios Git. Vê o guia.

    Como posso começar a aprender?

    Segue a ordem: HTML, CSS e JavaScript. Pratica com pequenos projetos e não tenhas medo de errar.
