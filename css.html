    CSS

    O que é CSS?

    CSS (Cascading Style Sheets) define o aspeto de uma página: cores, fontes, margens e posição dos elementos.

    Como adicionar estilos

    A forma mais organizada é um ficheiro separado, ligado no head:

    <link rel="stylesheet" href="style.css">

    Cores e fontes

    /* seletor { propriedade: valor; } */
h1 {
  color: #3b5bdb;
  font-family: Arial, sans-serif;
  font-size: 2rem;
}

    Margens e espaçamentos

    margin é o espaço por fora de um elemento; padding é o espaço por dentro.

    .caixa {
  margin: 20px;
  padding: 16px;
  background: #eef1ff;
}
