    HTML

    O que é HTML?

    HTML (HyperText Markup Language) é a linguagem que define a estrutura de uma página web. Usa etiquetas (tags) como <p> para dizer ao navegador o que é cada coisa: título, parágrafo, imagem, etc.

    Estrutura básica

    <!DOCTYPE html>
<html lang="pt-PT">
<head>
  <meta charset="UTF-8">
  <title>A minha página</title>
</head>
<body>
  <!-- Tudo o que se vê está aqui -->
</body>
</html>

    O head tem informação sobre a página. O body tem o conteúdo visível.

    Títulos e parágrafos

    <h1>Título principal</h1>
<h2>Subtítulo</h2>
<p>Isto é um parágrafo.</p>

    Imagens e links

    <img src="foto.jpg" alt="Descrição da foto">
<a href="https://github.com">Ir para o GitHub</a>

    Escreve sempre o atributo alt nas imagens: ajuda quem usa leitores de ecrã.
