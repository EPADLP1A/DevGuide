    JavaScript

    O que é JavaScript?

    JavaScript é a linguagem que torna as páginas interativas: reage a cliques, valida formulários, mostra mensagens, etc.

    Variáveis

    Uma variável guarda um valor com um nome.

    const nome = "Ana";   // não muda
let idade = 20;       // pode mudar
idade = 21;

    Funções

    function saudar(nome) {
  return "Olá, " + nome + "!";
}
alert(saudar("Ana"));

    Eventos e interações

    Um evento é algo que acontece na página, como um clique. Experimenta:

    const botao = document.getElementById("demo-btn");
botao.addEventListener("click", () => {
  document.getElementById("msg").textContent = "Olá!";
});
